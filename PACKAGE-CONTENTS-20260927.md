# Zynyro Full Project Package

This archive contains the complete application source, public assets, Supabase functions and migrations, package manifests, and project documentation.

- `.env.example` contains placeholders. Copy it to `.env` and enter your own Supabase project URL and publishable key.
- `.env`, `.git`, `node_modules`, and generated `dist` output are intentionally excluded.
- Install dependencies with `npm.cmd install`, check with `npm.cmd run build`, and run locally with `npm.cmd run dev`.
- Apply pending Supabase migrations only after reviewing them and linking the intended project.
